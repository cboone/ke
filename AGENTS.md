# ke

## Overview

A developer-focused CLI for ergonomic macOS Keychain access.

## Status

Early. `src/main.rs` is 11 lines and is the entire implementation. Everything around it, however,
is complete and opinionated: release automation, a Homebrew formula, four CI workflows, dependency
auditing, and scrut CLI tests. Treat the scaffolding as settled and the code as greenfield.

Because this tool reads and writes Keychain items, anything you add here handles secrets. Follow
the `handle-secrets` skill: never log a retrieved secret, never pass one as an argv parameter, and
prefer stdin or the Keychain API over environment variables.

## Structure

```text
src/main.rs           entire implementation, currently a stub
tests/scrut/          scrut CLI snapshot tests
Formula/              Homebrew formula
docs/                 plans and notes
Cargo.toml            crate manifest
rust-toolchain.toml   pinned toolchain
deny.toml             cargo-deny license and advisory policy
typos.toml            typo-checker config
cliff.toml            git-cliff changelog config
rustfmt.toml          formatting config
```

## Development

Run `make help` for the full list.

| Target             | What it does                                        |
| ------------------ | --------------------------------------------------- |
| `make build`       | Build the project                                   |
| `make test`        | cargo nextest, falling back to cargo test           |
| `make test-scrut`  | Build, then run the scrut CLI tests                 |
| `make lint`        | clippy                                              |
| `make fmt`         | Check formatting                                    |
| `make deny`        | cargo-deny: license and vulnerability policy        |
| `make audit`       | Audit dependencies for known advisories             |
| `make typos`       | Typo check                                          |
| `make lint-md`     | markdownlint                                        |
| `make lint-actions`| actionlint                                          |
| `make format`      | Prettier over non-Rust files                        |

CI is `.github/workflows/ci.yml`. Secret scanning runs in both `gitleaks.yml` and
`trufflehog.yml`; `release.yml` handles tagged releases. `CHANGELOG.md` is generated by git-cliff
from conventional commits, so commit messages are the changelog source, not a separate edit.
